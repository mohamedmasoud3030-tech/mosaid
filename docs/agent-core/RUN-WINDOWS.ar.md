# تشغيل Mosaid على ويندوز 10 — لابتوب 4 جيجا، Core i5

هذا الدليل لحالتك تحديداً: **بدون موبايل، بدون بوت تيليجرام، بدون تثبيت Go**.

## ما تحتاجه

| المطلوب | التفاصيل |
|---|---|
| ويندوز 10 (64-bit) | المعالج Core i5 مدعوم بالكامل |
| مساحة قرص | ~120 ميجا (البرنامج + ملفاتك) |
| إنترنت | مطلوب (الموديل يعمل على سيرفرات Google، لا على لابتوبك) |
| مفتاح Gemini مجاني | من `https://aistudio.google.com/apikey` — تحتاج حساب Google فقط |

الذاكرة: **لا تحتاج ترقية الرام**. قِسْتُ البرنامج أثناء جلسة كاملة (موديل + أدوات + قاعدة بيانات)
فكان استهلاكه **11 ميجا في الخمول و16 ميجا في الذروة**. مشكلتك في 4 جيجا هي وِيندوز والمتصفح، لا Mosaid.

## الخطوات (10 دقائق)

### 1) فك الضغط
فك ضغط `mosaid-windows-amd64.zip` إلى:

```text
C:\mosaid\
```

ليصبح عندك: `mosaid-cli.exe` و`mosaid.exe` و`start-mosaid.bat` و`config.example.json`.

### 2) مفتاح الـ API
1. افتح `https://aistudio.google.com/apikey` في المتصفح.
2. اضغط **Create API key** وانسخ المفتاح.
3. أنشئ المفكرة: `C:\mosaid\secrets\model.key`
4. الصق المفتاح في **سطر واحد** بدون مسافات أو أسطر إضافية، واحفظ.

> على ويندوز لا يعتمد Mosaid على صلاحيات `600` لأن NTFS يستخدم ACL مختلفاً.
> احفظ المفتاح داخل مجلد المستخدم (`C:\Users\<اسمك>\...`) فالمستخدمون الآخرون لا يقرؤونه.

### 3) ملف الإعداد
انسخ `config.example.json` إلى `config.json` في نفس المجلد، وعدّل ثلاثة أسطر فقط
(استخدم **`/`** أو `\\` مزدوجة في المسارات، لا `\` مفردة):

```json
{
  "data_dir": "C:/mosaid/data",
  "workspace_dir": "C:/mosaid/notes",
  "owner_telegram_id": 1,
  "model": {
    "base_url": "https://generativelanguage.googleapis.com/v1beta/openai",
    "api_key_file": "C:/mosaid/secrets/model.key",
    "name": "gemini-2.5-flash",
    "timeout_seconds": 60,
    "input_price_per_1m": 0,
    "output_price_per_1m": 0
  }
}
```

الأقسام الأخرى (`agent` و`limits`) اتركها كما هي — القيم الافتراضية مضبوطة للفئة المجانية.

### 4) التشغيل
انقر مزدوجاً على **`start-mosaid.bat`**، أو من نافذة أوامر:

```bat
cd C:\mosaid
start-mosaid.bat
```

سترى:

```text
Mosaid v0.15.0 — model gemini-2.5-flash · 9 tools · workspace C:/mosaid/notes
Type /help, or /exit to quit. Writes need /approve <token>.
```

جرّب بالترتيب:

```text
/tools
اكتب لي في notes/todo.md ثلاث مهام لليوم
/approve <التوكن الذي يظهر>
اقرأ notes/todo.md
```

## لماذا هذه الطريقة أفضل من غيرها لحالتك

1. **بدون تثبيت Go**: تنزيل Go يحتاج ~500 ميجا قرص، وبناء المشروع على 4 جيجا رام يُبطئ الجهاز دقائق.
   الملفات الجاهزة (`.exe`) تُشغّل مباشرة.
2. **`mosaid-cli` لا الخدّام**: وضع التيرمنال لا يحتاج بوت تيليجرام ولا منفذاً مفتوحاً ولا بقاءه شغّالاً
   24 ساعة. الخدّام مفيد فقط لو أردت التحكم من تيليجرام على موبايلك، أي لا ينطبق على «بدون موبيل».
3. **قيم افتراضية للفئة المجانية**: خطوات أقل = توكنات أقل = لا تصادم مع حدود Google، وإعادة المحاولة
   عند 429 تعني انتظاراً لا فشلاً.
4. **`GOMEMLIMIT=64MiB`** يضبطه المشغّل تلقائياً حتى لا ينافس البرنامج بقية نظامك.

## إن أردت التحكم من الموبايل لاحقاً
شغّل `mosaid.exe` (الخدّام) على اللابتوب مع بوت تيليجرام بعد إضافة قسم `telegram` إلى `config.json`،
واتركه يعمل. لا حاجة لحزمة الهاتف (Phase 14) إلا إذا أردت العمل واللابتوب مغلق.

## مشاكل شائعة

| الرسالة | السبب والحل |
|---|---|
| `telegram.token_file is required` | أنت تشغّل `mosaid.exe` وليس `mosaid-cli.exe`. للحالة الحالية استخدم `start-mosaid.bat`. |
| `model secret: ... no such file` | مسار `api_key_file` خطأ. استخدم `/` أو `\\`. |
| `model HTTP 400/403` | المفتاح خطأ أو الموديل غير متاح لحسابك. جرّب `gemini-2.5-flash`. |
| `model HTTP 429` | حد الفئة المجانية؛ البرنامج ينتظر ويعيد المحاولة تلقائياً. انتظر دقيقة. |
| `workspace_dir: ... must be a directory` | أنشئ المجلد `C:\mosaid\notes` أولاً. |
| النافذة تُغلق فوراً عند النقر المزدوج | شغّل من `cmd` لترى الرسالة، أو استخدم `start-mosaid.bat` الذي يوقف عند الخطأ. |

## أمان
- المفتاح يبقى في جهازك، ويُدقَّق أنه ملف نصي سطر واحد، ولا يُطبع في السجلات.
- أي كتابة ملف تتطلب `/approve` صريحاً، والموافقة صالحة لاستدعاء واحد فقط وترتبط بالمستخدم والمسار.
- الأدوات محصورة داخل `workspace_dir`؛ لا تستطيع الخروج عنه أو قراءة `.env` أو ملفات الأسرار.
- المحتوى الذي تقرؤه الأدوات يُعامل كبيانات لا كأوامر (حماية من حقن التعليمات).
