# خطة الـ Agent الشخصي — فريلانس

> وثيقة العمل | أُعدّت بعد جلسة "الـ grill" | خاص بك

---

## 1. مَن أنت؟ (الملف الشخصي)

| البُعد | الوضع الحالي |
|---|---|
| المستوى التقني | غير تقني (مهم: الحل لازم "بدون كود" قدر الإمكان) |
| مجال العمل | فريلانس متفرّق + رغبة بالتركيز على مجالات أقوى وأكثر نفعاً |
| العملاء | لسه في البداية — مفيش قاعدة عملاء ثابتة |
| الفلوس | مفيش أداة فواتير/محاسبة جاهزة — نبني من الصفر |
| الجهاز | موبايل أساساً |
| صلاحيات الـ agent | **"يجهّز، وأنا أُأكّد"** على كل فعل (رد، دفع، إرسال) |
| الخصوصية | سحابة معروفة (سهولة) مع وصول محدود للحسابات الحساسة |

---

## 2. ماذا يملك الـ agent؟ (الأدوات التي سنجهّزها)

جعلنا الأدوات مقابل **حاجات فعلاً تريحك**، لا من أجل التظاهر.

| # | الأداة / الوصول | تحلّ ماذا؟ | كيف تصل؟ | معايير "أُأكّد أنا" |
|---|---|---|---|---|
| 1 | **Office Hours / تقويم Google** | تنظيم المهام، مواعيد التسليم، تذكيرات المتابعة | اتصال تقويم من الحساب | تذكيرات فقط |
| 2 | **البريد (Gmail / Outlook)** | مسودة ورد على العملاء، تصفية، تنبيهات | اتصال بريد | الرد = أنا أُأكّد |
| 3 | **مستودع ملفات (Drive / Dropbox)** | وجهة تسليم الملفات، أرشفة، ربط الملف بالمشروع | اتصال تخزين | بدون |
| 4 | **إدارة العملاء (CRM بسيط)** | جدول عملاء، مراحل مشروع، تاريخ الفواتير | ملف/جدول يديره الـ agent | بدون |
| 5 | **فواتير** | توليد فاتورة، متابعة دفع، تذكير | قالب فاتورة + تقويم | "أُرسل" = أُأكّد |
| 6 | **محاسبة (مصاريف/دخل)** | تتبّع أرباح وخسائر، مسودة إقرار | جدول + صيغ | بدون |
| 7 | **مؤقّت/مجتمع العملاء** | بوابات/منصات فريلانس، حسابات استقبال دفع (Payoneer/Wise/PayPal) | لاحقاً | عند الشراء/الإرسال = أُأكّد |

> **ملاحظة حساسة:** الـ agent يقرأ ويجهّز في كل مكان، لكن **لا يُنفّذ** أي فعل خارجي (رد بريد، دفع، إرسال) قبل موافقتك الصريحة. هذا هو خيارك.

---

## 3. البنية المقترحة (لماذا هذه تحديداً؟)

**الاستنتاج:** الأفضل لغير التقني هو **ـ منصّة أوتوماتيك بدون كود + إدارة عملاء بسيطة** تعمل من الموبايل.

```
       أنت (موبايل)  ←— بطّل تحديث يدوي —→
                │
        ════ (منصّة أوتوماتيك no-code: n8n أو مايعادلها) ════
                │   "الـ agent" الذي يربط كل حاجة
   ┌────────────┼────────────────┬─────────────┐
   │            │                │             │
 Mail + Calendar + Drive + CRM/جدول + (فواتير/محاسبة لاحقاً)
   │            │                │             │
   └────── كل شيء يرفع إليك للتأكيد قبل أي فعل ──────┘
```

**لماذا هذه البنية:**
- **بدون كود:** لا تحتاج برمجة، فقط وصلات واضحة.
- **مانع للأخطاء:** (مبدأ "يجهّز، وأنا أُأكّد") يمنع أي تصرّف مفاجئ بفلوسك أو رسائلك.
- **يعمل على الموبايل:** تدير كل شيء من التليفون، وتبقى سحابياً.
- **قابلة للنمو:** تضيف عملاء وفواتير ومحاسبة دون إعادة بناء.

## 4. خارطة الطريق (مراحل — لا تفعلها كلها دفعة واحدة)

### المرحلة 1 — الأساس (أول أسبوع)
- [ ] تحديد **المنصّة** (سحابة معروفة) وإنشاء حساب.
- [ ] وصول الـ agent إلى **البريد + التقويم** بصلاحيات محدودة.
- [ ] إنشاء **جدول عملاء (CRM)** بسيط.

### المرحلة 2 — تسليم الشغل (أسبوع 2)
- [ ] ربط **مستودع الملفات** بحيث يجمع المشروع وملفاته تلقائياً.
- [ ] قالب **عرض سعر + عقد** جاهز يملأه الـ agent من بروفايل العميل.
- [ ] تأكيد الـ agent لتفاصيل (المبلغ، الموعد، المتطلبات) قبل إرسال.

### المرحلة 3 — الفلوس (أسبوع 3)
- [ ] قالب **فاتورة** ومتابعة دفع وتذكير.
- [ ] جدول **مصاريف/دخل** ومُلخّص أرباح شهري.
- [ ] ربط **حساب استقبال دفع** (Payoneer/Wise/PayPal) والبدء بتجمّع دخل.

### المرحلة 4 — نموّ (شهرياً)
- [ ] جعل الـ agent يتنبّأ بالمهام الجارية وتجهيزها.
- [ ] إضافة "أداة فرص" تقترح مشاريع تناسب مجالك الأقوى (توجّه اختيارك).
- [ ] لاحقاً: إن واصلت، اتّجه للسحابة الخاصة عند الحاجة لخصوصية أعلى.

---

## 5. ما يجب أن أفعله أنا (المستخدم) — ما الذي يتطلّب منك؟

أولاً: لست تقنياً، لذا:
- الـ agent يجهّز ويقترح، **وأنا أُأكّد** — لا توجد "موافقة صامتة".
- لا تضع كلمات سر/بيانات حساسة كاملة داخل الـ agent؛ فالتطبيق يعطي **وصولاً محدوداً** وليس مفتاحاً كاملاً.
- أختار مجال "أقوى" من المجالات المتفرّقة، ليكثّف الـ agent جهده نحو الأكثر ربحاً/منفعةً.

## 6. ملاحظة: محتاج تأكيد (قبل التنفيذ)

> قبل أن أبدأ ببناء أي شيء فعلي، أحتاج تأكيدك على **البندَين التاليَين**:
> - **أدوات الدفع:** Payoneer أم Wise أم PayPal أم بنك؟ (الذي سيعتمد عليه الـ agent)
> - **المنصّة:** هل تفضّل **n8n (سحابي, أوتوماتيك بدون كود، أفضل للربط)** أم **مساعد سحابي جاهز (أسهل، ربط أوسع)**؟
>  يمكنك أيضاً اختيار البنية بعد أن أُعرض عليك المقارنة.
