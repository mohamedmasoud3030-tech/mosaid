# دليل تشغيل Mosaid على هاتف الأندرويد (مالك المشروع)

هذا الدليل لك خطوة بخطوة. لا تحتاج أي خبرة تقنية — كل خطوة مكتوبة حرفيًا.

---

## قبل البدء: تأكد من ٣ أشياء فقط

1. **Termux** مثبّت على الهاتف (من F-Droid).
2. **بوت تيليجرام خاص** جاهز ولديك توكنه (Token) — إذا لم يكن جاهزًا، أنشئه مرة واحدة:
   - افتح تيليجرام وابحث عن `@BotFather`.
   - أرسل له `/newbot` واتبع الخطوات (اسم البوت ثم اسم مستخدم ينتهي بـ bot).
   - سيعطيك رسالة فيها **Token** يشبه `123456789:AAH...` — انسخه واحفظه.
3. **حساب Google** عادي (للمفتاح المجاني — بدون أي بطاقة بنكية).

---

## الخطوة ١: مفتاح Gemini المجاني (دقيقتان)

1. افتح من متصفح الهاتف: `https://aistudio.google.com/apikey`
2. سجّل الدخول بحساب Google.
3. اضغط **Create API key** ثم انسخ المفتاح (يبدأ بـ `AIza...`).
4. احفظه جانبًا. **لا حاجة لأي دفع أو بطاقة — إطلاقًا.**

> ملاحظة خصوصية مهمة: الطبقة المجانية من Google قد تستخدم المحادثات لتحسين نماذجها.
> لذلك **لا تضع أسرارًا** (كلمات مرور، مفاتيح، بيانات حساسة) في محادثات البوت.

---

## الخطوة ٢: تنزيل الحزمة داخل Termux

افتح تطبيق Termux وانسخ السطرين التاليين واحدًا تلو الآخر
(استبدل `LINK` برابط ملف `mosaid-phone-kit.tar.gz` من صفحة إصدار GitHub للمشروع):

```
curl -L -o kit.tar.gz "LINK"
curl -L -o kit.tar.gz.sha256 "LINK.sha256"
```

ثم تحقق من سلامة الملف (يجب أن يطبع `OK`):

```
sha256sum -c kit.tar.gz.sha256
```

وفك الضغط:

```
tar -xzf kit.tar.gz
```

> بدون أي إذن لملفات الهاتف — الحزمة تعمل داخل Termux فقط.

---

## الخطوة ٣: التثبيت (أمر واحد + ٥ إجابات)

شغّل المثبّت:

```
bash mosaid-phone-kit/phone/install-phone.sh
```

وسيجدّث الحزم ثم يسألك خمسة أسئلة:

1. **رقم مالك تيليجرام (رقمي):** احصل عليه مرة واحدة بإرسال أي رسالة لـ `@userinfobot`
   في تيليجرام (رقم مثل `123456789`).
2. **توكن البوت:** ألصق الـ Token — **لن يظهر على الشاشة** (يُكتب مخفيًا).
3. **عنوان مزوّد النموذج:** اضغط Enter للافتراضي (Gemini المجاني).
4. **اسم النموذج:** اضغط Enter للافتراضي (`gemini-2.5-flash`).
5. **مفتاح النموذج:** ألصق مفتاح `AIza...` — **يُكتب مخفيًا أيضًا**.

بعدها سيتحقق المثبّت من كل شيء ويشغّل الخدمة، وتظهر لك قائمة خطوات أندرويد يدوية.

---

## الخطوة ٤: خطوات أندرويد اليدوية (مرة واحدة)

1. ثبّت **Termux:Boot** من نفس مصدر Termux وافتحه مرة واحدة.
2. من إعدادات أندرويد → التطبيقات → Termux و Termux:Boot → البطارية → **Unrestricted**
   (غير مقيد).
3. افتح Termux وتأكد من ظهور إشعار دائم يفيد بوجود wake lock (منع النوم).
4. شغّل فحص الشبكة داخل Termux:

```
~/.local/share/mosaid/scripts/preflight.sh --network
```

يجب أن ترى `network_telegram: reachable` و `network_model: reachable`.

---

## الخطوة ٥: أول اختبار

1. افتح تيليجرام وافتح بوتك، وأرسل:

```
/status
```

2. يجب أن يرد خلال ثوانٍ بشيء مثل: `Mosaid v0.14.0 status=running ...`
3. جرّب محادثة عادية معه، ثم جرّب الذاكرة:

```
/remember مشروعي اسمه Mosaid
/memory مشروعي
```

4. الأوامر المتاحة: `/status` و`/help` و`/stop` و`/memory <بحث>` و`/remember <نص>`
   و`/forget <رقم>` و`/export` و`/approve` و`/deny`.

---

## الخطوة ٦: سيناريو أول ٣٠ دقيقة

- اترك الهاتف يعمل بشكل طبيعي (مع wake lock و Termux:Boot).
- خلال ٣٠ دقيقة أرسل **٦ رسائل على الأقل** مرقّمة مثل: `M14-01-001`، `M14-01-002`...
  بفاصل ٥ دقائق تقريبًا، وتأكد أن البوت يرد على كل واحدة.
- لا ترسل أكثر من ١٠ رسائل في الدقيقة (حدود الطبقة المجانية).
- بعد الانتهاء اجمع التقرير داخل Termux:

```
~/.local/share/mosaid/scripts/collect-diagnostics.sh
```

سيظهر لك مسار ملف مضغوط في مجلد `reports` — احتفظ به لنفسك (لا تشاركه مع أحد).

---

## إذا لم يردّ البوت

1. أرسل `/status` مرة أخرى وانتظر ١٥ ثانية.
2. داخل Termux شغّل:

```
sv restart mosaid
```

3. لمشاهدة السجل (لا يحتوي أسرارًا — تُحجب تلقائيًا):

```
ls ~/.local/share/mosaid/logs
```

4. لتشغيل يدوي أمامك مباشرة (ترى كل شيء وتوقفه بـ Ctrl+C):

```
~/.local/share/mosaid/scripts/run-foreground.sh
```

5. رسالة الخطأ `429` تعني تجاوز حد الطبقة المجانية — انتظر دقيقة وأعد المحاولة.

---

## ملاحظات أخيرة

- البوت يرد **عليك أنت فقط** (رقمك المسجّل)، وكل الأدوات الخطرة معطلة.
- التحديث أو تغيير المزوّد: أعد تشغيل `install-phone.sh` وأجب بالبيانات الجديدة.
- أي شيء غريب تشاهده: شغّل `collect-diagnostics.sh` واحتفظ بالملف — سيُطلب عند المراجعة.
